수집기 설정 (네이버 API · 자동 수집)

여기 적은 키는 이 컴퓨터의 확장 안에만 저장돼요. 사이트·채팅·Claude로는 키를 보내지 않고, 불러온 숫자(검색량·트렌드·최저가)만 사이트로 넘겨요.

① 네이버 개발자센터 (쇼핑 검색 · 데이터랩)

developers.naver.com → Application 등록 → 사용 API에 검색과 데이터랩(검색어트렌드) 추가 → 발급된 Client ID/Secret.

② 네이버 검색광고 (월간 검색량 · 경쟁도)

searchad.naver.com → 도구 → API 사용 관리 → 엑세스라이선스·비밀키 발급. CUSTOMER_ID는 같은 화면에 있어요. 광고를 집행하지 않아도 발급돼요.

내 블로그 아이디

blog.naver.com/아이디 — 새로 올라간 글을 RSS로 확인해 사이트의 ‘게시 확인’을 자동으로 채워요.

③ 더 볼 키워드 (선택)

사이트를 열면 상품·시즌·추천 키워드를 자동으로 받아 와요(최대 30개). 꼭 보고 싶은 키워드가 있으면 줄마다 하나씩 적어요.

④ 자동 수집 화면

블로그 통계·쇼핑커넥트 성과처럼 자주 보는 화면을 열고 확장 아이콘 → 이 화면 매일 자동으로 읽기로 등록해요. 매일 9시·21시 무렵 뒤쪽 탭으로 잠깐 열어 읽고 닫아요. 사이트에서 ‘읽어서 담기’로 확인한 뒤 저장돼요.

    어떻게 동작하나요?

    • 6시간마다 한 번, 키워드마다 쇼핑 검색 1번 + 데이터랩 5개당 1번 + 검색광고 5개당 1번을 불러요. 하루 무료 한도(검색 25,000·데이터랩 1,000회) 안이에요.
    • 결과는 확장 보관함에 들어가고, 사이트를 열면 자동으로 저장돼요. 실패한 API는 사이트에 ‘불러오지 못함’으로 그대로 보여요.
    • 마이리얼트립·쇼핑커넥트·세시간전·애드포스트는 공개 API가 없어 지금처럼 ‘이 화면 보내기’로 담아요.
