# 써즈 동네방네 수집기 (Chrome 확장)

로그인해 둔 **내 브라우저**에서 네이버 블로그 통계, 쇼핑커넥트(브랜드커넥트), 마이리얼트립·여행 커넥트, 세시간전, 애드포스트 화면을 읽어 써즈의 동네방네 사이트로 보내요. 비밀번호·쿠키·입력칸 값은 읽지 않고, 화면에 보이는 글자와 표만 모아요. 화면 읽기는 버튼을 누를 때만 하고, 혼자 네이버 화면에 접속하지 않아요.

키를 넣으면 **네이버 공식 API**(쇼핑 검색 · 데이터랩 검색어 트렌드 · 검색광고 키워드 도구)도 6시간마다 불러와요. 이때만 확장이 혼자 `openapi.naver.com`, `api.searchad.naver.com`에 접속해요.

## 설치 (한 번)
1. 이 `extension` 폴더를 내 컴퓨터에 받아요(GitHub 저장소 → Code → Download ZIP 후 압축 풀기).
2. Chrome 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기 → **압축해제된 확장 프로그램을 로드합니다** → `extension` 폴더 선택.
3. 퍼즐 아이콘에서 ‘써즈 동네방네 수집기’를 고정해요.

## 쓰는 법
1. 네이버 블로그 통계, 쇼핑커넥트 상품 검색·성과, 마이리얼트립 파트너 화면 등을 열어요.
2. 확장 아이콘 → **이 화면 보내기**.
3. 써즈의 동네방네 사이트를 열면 오른쪽 아래 **확장에서 받은 자료 N개** 버튼이 나타나요 → **읽어서 담기** → Claude가 숫자를 옮기면 확인하고 저장해요.
4. 버튼이 안 나타나면: 사이트 탭에서 확장 아이콘 → **이 탭의 사이트와 연결**을 한 번 눌러 허락해요. 그래도 안 되면 **마지막 자료 복사** 후 사이트의 ‘캡처로 담기/캡처로 성과 입력’ 칸에 붙여넣어요.

화면 종류는 주소로 짐작해요(통계·글별 조회·상품 목록·수익). 사이트에서 저장하기 전에는 아무 기록도 바뀌지 않아요. 보관함은 최근 20개까지 남아요.

## 네이버 API 자동 연결 (선택)
수익·상품 → ‘팔기 좋은 키워드’의 **규모(월 검색량)·경쟁(광고 경쟁도)·급등(데이터랩 최근 4주 변화)** 과 쇼핑 최저가를 채워요.

1. 키 준비
   - 네이버 개발자센터(developers.naver.com) → Application 등록 → 사용 API: **검색**, **데이터랩(검색어트렌드)** → Client ID / Client Secret
   - 네이버 검색광고(searchad.naver.com) → 도구 → API 사용 관리 → 엑세스라이선스 / 비밀키 / CUSTOMER_ID (광고 집행 없이 발급돼요)
2. 확장 아이콘 → **API 설정** → 키 입력 → **저장하고 지금 불러오기**
3. 사이트를 열면 결과가 자동으로 저장돼요(Claude 판독 없이 숫자 그대로). 실패한 API는 키워드 탭에 ‘못 불러온 것’으로 그대로 보여요.

- 키는 이 확장의 `chrome.storage.local`에만 저장돼요. 사이트·채팅·GitHub로 보내지 않아요.
- 불러올 키워드: 사이트를 열 때 넘겨주는 상품·시즌·추천 키워드(최대 30개) + 설정에 직접 적은 키워드.
- 쇼핑 검색 결과는 상품 찾기의 ‘네이버 쇼핑 (API)’ 칸에 담겨요. 제휴 수수료·판매 순위가 아니므로 추천 상품·판매 점수에는 쓰지 않아요.
- 마이리얼트립·쇼핑커넥트·세시간전·애드포스트는 공개 API를 찾지 못해 기존처럼 ‘이 화면 보내기’로 담아요.
- 업데이트: 새 폴더로 바꾼 뒤 `chrome://extensions`에서 새로고침(↻). 키를 처음 넣을 때 네이버 두 주소 접속 권한을 묻는 건 정상이에요.
