# 써즈의 동네방네 — 개발 명세

개인용 콘텐츠 운영 사이트. 한국 시간 기준. 회원 공유 기능 없음. 소유자 비공개 Sites 접근 및 추가 관리자 비밀번호 검증. 비밀번호는 서버 비밀값이며 소스에 포함하지 않는다.

## 확정된 운영 규칙
- 블로그 직접 작성 2~3개/일, 밀린 글은 다음 날로 이동하되 직접 작업은 4개/일 이하. 협찬 마감과 엠바고 우선, 일정 충돌은 알림으로 노출.
- 자동 글은 별도 2개/일, 한국 시간 01:00: 아시아 여행 이슈 1개, 쇼핑 커넥트 1개. 연동 미확인 시 자동 발행된 것처럼 표시하지 않는다.
- 지역은 도시/광역 단위로 구분. 같은 날 및 전후 날짜의 지역 반복을 가능한 줄인다. 후보가 부족하면 이유 표시.
- 1~2개월 발행 계획. 협찬·예약·명시적으로 잠근 일정은 변경 제한. 검색량 데이터가 없으면 소재 다양성/직접 입력 우선순위로 추천하고 검색량 기반이라고 표시하지 않는다.
- 영상 원본 2~3개/주. 원본 2개 기본+선택 1개, 쇼츠/틱톡/릴스로 연결. 채널마다 별도의 원본 제작 과제를 만들지 않는다.
- 블로그·인스타·스레드 운영 중. 샤오홍슈·틱톡·유튜브 다음 주 시작.
- 하루 방문자 약 500~600(사용자가 말한 기준), 목표 1,000. 라이브 통계와 구분. 7일 평균 성장 이정표 650/750/850/1,000.

## 글쓰기
콘텐츠 유형: 빠른 정보·이슈, 여행 정보·날씨, 여행 후기, 협찬·체험단, 상품·제휴, 짧은 영상, SNS 글.
빠른 정보·이슈는 주제만으로 시작하고 공식 일정·장소·참여 방법·비용 확인. 필수 긴 도입이나 4~5개 소제목을 강제하지 않음. 후기·협찬은 사용자 구성과 사진 순서를 따름.
초안은 복사하기 쉬운 일반 텍스트. 조사 출처·검수·확인 필요 정보는 별도. 사진 위치 표시는 요청 시에만.

## 고정 편집 원칙
실제 경험·생생한 사용자 표현을 최우선으로 보존. 경험을 추측하거나 외부 후기를 본인 경험으로 바꾸지 않음. 기억이 안 나는 부분은 제외하고 반복 질문 안 함. 충분한 자료면 질문하지 않고 필요한 질문만 최대 3개.
사진·메뉴판, 사용자 경험, 가이드라인, 공식 홈페이지·SNS, 지도·예약페이지, 최근 후기, 일반검색 순으로 참고하되 방문 당시 정보와 현재 변경 정보를 시점별로 구분. 충돌은 알리고 단정하지 않는다.
가이드라인 전체 읽기 후 업체/지점, 제공 항목, 고지, 키워드/횟수, 필수 내용, 글자·사진·영상 조건, 지도·링크·태그·금지 표현·마감·수정 조건 추출. 실제 사용횟수 검수.
광고 고지는 실제 제공 조건에 맞게 상단 표시. 협찬에 내돈내산 등 금지. 키워드는 정확한 띄어쓰기 유지. 제목은 실제 다루는 내용만, 과장·거짓 긴급성 금지.
짧은 모바일 문단과 ~했어요/~더라고요 중심. ㅎㅎㅎ/이모지는 감정에 맞게 절제. 상투적 AI 홍보 문체와 근거 없는 감탄 금지.
정보→실제 경험→독자 팁. 비교 목적일 때만 표. CTA는 독자의 고민과 선택 기준 뒤에 자연스럽게. 가격·혜택 조건을 숨기지 않음.
수정은 요청 범위만, 사용자 구조·표현 유지. 전체 재작성 요청 시 최신 지침 모두 반영. 변경 부분만 볼드 요청 시 실제 변경 부분만.
자동 글은 미사용 상품·미방문 현장을 실제 후기처럼 쓰지 않음. 이미지 사용권 확인 및 출처 기록. 생성 이미지는 실제 상품/현장 사진으로 표현하지 않음.

## 학습과 리포트
텍스트·파일·URL 입력에서 체크하면 별도 학습 페이지. 원본/요약/학습 포인트/적용점/분야/적용 상태 기록. 접근 실패 자료는 학습 완료로 표시하지 않는다.
주간 성과 리뷰로 추천 기준 변경 이유를 기록. 기존 고정 편집 규칙은 자료 입력으로 덮어쓰지 않음.
작업은 예정/진행 중/완료/확인 필요/실패. 일일 작업/발행/일정 변경, 주간 성과/제휴/추천 리뷰. 일반 완료 알림은 묶고 실패·마감은 우선 표시.

## 디자인
넓은 ERP 작업 영역에 원작을 복제하지 않는 파스텔 파랑 판타지 RPG 창 테두리, 캐릭터 2~3등신, 퀘스트 로그와 XP. 캐릭터는 참고 얼굴이 도착하기 전 임시 캐릭터라고 표시. 퀘스트는 실제 노력으로 성장하고 쉬는 날 페널티·연속 출석 강요 없음.

## 검증 및 연결 대기
네이버 발행·통계, 검색량, SNS 통계·게시, 브랜드 커넥트·세시간전 전환, AI 실행 서비스는 연결·실측 전 대기 상태. 조회수/검색 클릭률/링크 클릭률/전환율의 분모는 별도. 통계 CSV는 제공된 범위만 분석. 사이트 로그인, 저장, 일정, 편집, 학습, 검수, 보고서, 설정은 서버 저장 기능으로 검증.
