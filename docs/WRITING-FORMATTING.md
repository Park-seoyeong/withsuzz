# 써즈 글 꾸미기

글쓰기 작업실 → 원고 → `써즈 꾸미기`에서 인용구·소제목·글자 크기·색·굵게·문단 정렬·줄 간격을 저장하고 미리볼 수 있습니다. 원문은 복사 가능한 일반 텍스트로 보존하며 서식은 별도로 저장합니다. `직접 지정한 서식 지우기`는 원고 내용을 변경하지 않습니다.

- 문단에 커서를 두거나 원고의 일부 문장을 선택한 다음 적용합니다. 정렬과 줄 간격은 문단에 적용합니다.
- 서식은 원고 SHA-256에 연결합니다. 원고 변경 후 이전 위치에 임의 재적용하지 않고 다시 확인하도록 표시합니다.
- 실제 기존 글 관측은 `/api/formatting-agent` POST `op: study`로 저장하며 학습 자료실에서 출처를 확인합니다. 같은 실행 기록은 중복 저장되지 않습니다.
- 콘텐츠 유형별 프로필은 보관된 관측 중 같은 URL의 최신 자료를 참고합니다. 관측된 값이 일치하는 속성만 자동 기본값으로 사용합니다.
- 화면 관측만으로 픽셀 크기·색상 코드·글꼴·줄 간격을 추정하지 않습니다. 계산된 본문 스타일로 확인된 값만 프로필에 적용합니다. 화면에서 본 강조와 여백 등은 관측 기록으로 남깁니다.
- ChatGPT 작성 문맥에 서식 프로필과 현재 문단별 계획을 함께 전달합니다. owner-private 에이전트는 POST `op: apply`로 정확한 원고 해시와 문단/문장 서식만 저장할 수 있습니다. 본문·발행 상태는 수정하지 않습니다.
- 발행 준비에는 제목을 제외한 본문에 맞춰 문단·범위 정보를 연결합니다. 준비 뒤 서식이나 프로필이 바뀌면 다시 검수합니다. 커스텀 서식이 있는 글의 예약·게시 성공 기록은 `formattingVerified: true`가 있어야 수락합니다.
