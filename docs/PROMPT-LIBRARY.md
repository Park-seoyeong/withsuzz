# 내 프롬프트 라이브러리

다른 프로젝트에서 쓰던 프롬프트를 사이트 안에 보관하고, 글쓰기 작업실에서 골라 바로 쓰는 기능입니다. 프롬프트를 복사해 GPT 창을 다시 여는 과정을 줄이는 것이 목적입니다.

## 사용 흐름

1. `관리자 설정 → 내 프롬프트 라이브러리`에서 이름·내용(최대 20,000자)·쓰는 콘텐츠 유형·메모를 저장합니다. `.txt`/`.md` 파일로도 불러올 수 있습니다.
2. 하나를 `기본으로` 지정하면 글쓰기 작업실에서 해당 유형일 때 자동으로 선택됩니다. 유형을 비워 두면 모든 유형에 적용됩니다.
3. 글쓰기 작업실 상단 `내 프롬프트`에서 고른 뒤 초안·수정안을 요청합니다.
   - 사이트에서 바로 생성(API): 요청 시점의 프롬프트 내용을 고정해 AI 요청에 `userPrompt`로 넣습니다.
   - ChatGPT 대화에서 작성: 요청에 프롬프트 ID를 남기고, 플러그인이 작성 자료를 읽을 때 함께 받습니다. 그 사이 프롬프트가 삭제되면 `promptNotice`로 알리고 기본 원칙만 적용합니다.
   - 작성 프롬프트 복사: 복사되는 지시문 끝에 고른 프롬프트가 붙습니다.
4. AI 결과 카드에 사용한 프롬프트 이름이 표시되고, 라이브러리에 사용 횟수·최근 사용일이 기록됩니다.

## 우선순위

고정 편집 정책(`worker/editor-policy.mjs`)과 관리자 기본 프롬프트가 먼저 적용됩니다. 추가 프롬프트의 구성·말투·형식 요청은 반영하지만, 경험을 만들지 않기·협찬 고지·최신 정보 확인·출력 구조와 충돌하면 고정 규칙을 따르고 충돌 내용은 결과의 확인 사항(warnings)에 표시하도록 지시합니다.

## 제한

- 최대 40개, 이름 60자, 내용 20,000자, 메모 300자. 같은 이름은 저장하지 않습니다.
- 내용이 바뀔 때만 버전이 올라갑니다. 진행 중인 API 요청은 요청 시점의 내용을 사용합니다.
- 프롬프트는 전체 JSON 백업(`state.prompts`)에 포함됩니다.
- 사이트 즉시 생성은 여전히 서버의 `OPENAI_API_KEY`가 있어야 실제로 동작합니다. 키가 없으면 ChatGPT 방식과 프롬프트 복사로 같은 프롬프트를 사용할 수 있습니다.
