# 써즈님 Cloudflare 계정으로 옮기기

ChatGPT 사이트 대신 써즈님 명의의 Cloudflare 계정(무료 요금제)에서 같은 사이트를 운영하는 방법입니다. 화면·기능은 그대로이고, 주소와 데이터 저장 위치만 바뀝니다.

## 1. 준비 (한 번만)

1. https://dash.cloudflare.com 에 가입하고 이메일 인증을 마칩니다.
2. 왼쪽 메뉴 **R2 객체 스토리지**를 열고 사용을 시작합니다. 사진·PDF 첨부를 저장하는 곳이에요. 무료 한도(10GB) 안에서는 요금이 없지만, 활성화할 때 결제 수단 등록을 요청할 수 있어요.

## 2. GitHub 저장소로 배포

1. **Workers 및 Pages → 만들기 → 저장소 가져오기(Import a repository)** 를 누릅니다.
2. GitHub 계정을 연결하고 `Park-seoyeong/withsuzz` 저장소를 고릅니다.
3. 설정값
   - 프로젝트 이름: `withsuzz-manager`
   - 브랜치: `claude/upbeat-newton-ay3cuo` (나중에 main에 합치면 main)
   - 빌드 명령: `npm ci`
   - 배포 명령: `npx wrangler deploy`
4. **저장하고 배포**를 누릅니다. 데이터베이스(D1)와 파일 저장소(R2)는 첫 배포 때 자동으로 만들어집니다.

이후에는 이 브랜치에 코드가 올라올 때마다 자동으로 다시 배포됩니다.

## 3. 비밀값 넣기

배포된 Worker → **설정 → 변수 및 비밀(Variables and Secrets)** 에서 **비밀(Secret)** 로 추가합니다. 값은 화면에만 입력하고 채팅·파일에는 쓰지 않습니다.

| 이름 | 필수 | 설명 |
|---|---|---|
| `ADMIN_PASSWORD` | 필수 | 사이트에 들어갈 때 쓰는 관리자 비밀번호. 없으면 로그인이 막혀 있어요. |
| `ANTHROPIC_API_KEY` | AI 쓰려면 | Claude API 키. 넣으면 ‘사이트에서 바로 생성’이 켜져요. |
| `OPENAI_API_KEY` | 선택 | OpenAI를 쓰고 싶을 때만. 둘 다 있으면 OpenAI가 먼저예요(`AI_PROVIDER=anthropic`으로 바꿀 수 있어요). |
| `AGENT_TOKEN` | 선택 | 자동화(통계 수집·ChatGPT 에디터 연결)가 이 사이트에 접근할 때 쓰는 긴 임의 문자열. 없으면 자동화 경로는 모두 막혀요. |

저장하면 바로 적용됩니다.

## 4. 접속과 자료 옮기기

1. `https://withsuzz-manager.<내 하위 도메인>.workers.dev` 를 엽니다. 주소는 Worker 개요 화면에 나와요.
2. `ADMIN_PASSWORD`로 로그인합니다.
3. 예전 ChatGPT 사이트의 **관리자 설정 → 전체 자료 백업**으로 JSON을 내려받습니다.
4. 새 사이트의 **관리자 설정 → 백업 파일로 복원**에서 그 파일을 고릅니다. 글감·원고·협찬·학습·성과·XP·설정·프롬프트가 옮겨져요.
5. 사진·PDF 원본은 백업 JSON에 들어 있지 않아요. 필요한 글에서 다시 첨부해 주세요.

## 보안

- 이 모드(`STANDALONE=1`, `wrangler.toml`에 설정됨)에서는 외부에서 보낸 신원 헤더를 무시하고 관리자 비밀번호와 로그인 세션으로만 들어갈 수 있어요. 비밀번호를 8번 틀리면 15분간 막혀요.
- 자동화 경로(`/api/*-agent`, `/api/naver-sync` 등)와 `/mcp`는 로그인 세션이나 `AGENT_TOKEN`이 있어야 열려요.
- ChatGPT 사이트와 달리 주소 자체는 인터넷에 열려 있어요. 한 겹 더 막고 싶으면 Cloudflare **Zero Trust → Access**에서 이 주소에 이메일 인증을 걸 수 있어요(무료).

## 옮겨지지 않는 것

- ChatGPT 쪽 예약 작업(오전 9시 네이버 통계 갱신, 오후 6시 운영 매니저)은 예전 사이트로 자료를 보내요. 새 사이트로 받으려면 그 작업의 주소를 새 주소로 바꾸고 `Authorization: Bearer <AGENT_TOKEN>`을 붙여야 해요. 바꾸기 전까지 새 사이트의 통계는 복원한 시점에 멈춰 있어요.
- ChatGPT 전용 에디터 플러그인도 예전 사이트에 연결돼 있어요.
- 예전 사이트는 지우지 않아도 돼요. 새 사이트가 잘 돌아가는 걸 확인한 뒤 정리하세요.

## 직접 확인한 범위

로컬의 Cloudflare 실행 환경(wrangler dev, workerd)에서 다음을 확인했어요.
- 빈 데이터베이스에 표 자동 생성
- 잘못된 비밀번호 거절과 로그인
- 자동화 경로 토큰 검사
- 백업 복원, 프롬프트 저장
- 첨부 파일 R2 저장·다운로드
- Claude SDK가 Claude API까지 요청을 보내는 것(일부러 틀린 키를 넣어 “키 확인 필요”를 받음)

실제 써즈님 계정 배포와 진짜 키로의 생성은 아직 확인 전이에요.
