# 외부 여행 키워드 추천

홈과 키워드 추천 화면에서 최신 Google 급상승 검색(한국)과 Google 뉴스 여행·축제·항공 RSS, Bing 여행 뉴스 RSS를 직접 조회합니다. 한 뉴스 공급자가 실패해도 다른 공급자의 실제 자료를 사용할 수 있습니다. 화면을 열거나 돌아오면 확인하고, 화면이 보이는 동안 15분마다 갱신합니다. 서버도 15분간 마지막 요청을 재사용하므로 반복 클릭으로 추가 호출하지 않습니다. 사이트를 닫아 둔 동안 상시 수집하는 예약은 이 기능에 포함되지 않습니다.

- Google 급상승 피드의 `approx_traffic`는 근사 표시값입니다. 기간이 명시되지 않은 표시값을 일간 검색량으로 바꾸지 않습니다.
- 뉴스 제목에서 추출한 키워드는 글감 제안입니다. 가져온 기사 표본 수는 검색량·시장 전체 기사 수·상승률이 아닙니다.
- 0~100점은 편집 우선순위입니다. 최신성 최대 15, 실제 검색 신호 최대 35, 기사 표본 최대 15, 블로그 유입 연결 15, 여행 적합도 15/쇼핑 10, 사진·구성 준비 5를 더하고 최근 발행 중복 20, 오늘 같은 지역 10, 오래된 수집 20을 뺍니다. 점수 구성과 근거를 화면에서 확인합니다.
- 게시 시각이 48시간을 넘긴 자료·확인되지 않은 날짜는 제외합니다. 1시간 이상 지난 수집은 경고하며 7일을 넘긴 블로그 유입 자료는 추천 가점으로 사용하지 않습니다.
- 피드 실패 시 마지막 실제 자료와 성공 시각을 보존합니다. 수집 실패를 최신 분석 완료로 기록하지 않습니다.
- 네이버 데이터랩·다음 지수와 Google Trends 기간별 상대 지수는 별도 연동 전입니다. 조회수·매출·클릭률을 추정해 제공하지 않습니다.

## 연결 경로

소유자 비공개 Sites dispatch 뒤의 `/api/trends-agent`는 GET으로 분석을 조회하고 POST `{op:"refresh"}`로 정해진 세 공개 피드만 수집합니다. 브라우저 요청은 관리자 세션과 Origin 검사를 유지합니다. 임의 URL·지수 업로드는 받지 않습니다.

추천 선택은 `/api/action`의 `chooseTrendRecommendation`입니다. 현재 스냅샷 시각과 추천 ID를 확인하고 근거를 보관합니다. 같은 스냅샷의 중복 선택은 글감을 추가하지 않습니다. 맞는 날짜 미정 보관함 글감이 있으면 그대로 사용하고 기존 원고·메모·일정·게시 상태를 보존합니다. 새 글감은 일정 없는 아이디어로 만들어집니다. 선택 자체로 발행이나 경험치를 기록하지 않습니다.
