# 과거 글 재작성 추천

## 데이터와 비교

전체 네이버 방문자·검색어 통계와 글별 성과를 분리한다. 기존 오전 9시 통계 갱신, 프로필과 예약 ID를 변경하지 않는다. 일별 글 성과는 사이트 CSV 또는 TinyFish에서 실제 읽은 글별 일간 조회수 수집 결과로 받는다. `/api/naver-post-sync`는 실제 소유 게시글 링크와 수집 출처·실행 URL을 검증해 별도 저장한다. 블로그 전체 통계 갱신은 별도 보존한다.

CSV 열: date,title,channel,itemId,url,source,visits,views,clicks,conversions,revenue,impressions,searchClicks,keyword. date는 실제 하루, source는 동일한 수집 출처, itemId 또는 url은 보관함에 등록된 원본 글에 정확하게 연결한다. 제목 유사성으로 글을 연결하지 않는다. views는 조회수이고 visits는 방문 유입이다. keyword가 채워진 행은 키워드별 세부 자료로 취급해 글 전체 성과와 중복 합산하지 않는다. 기간 합계는 가져오지 않는다.

빈 셀은 null, 명시한 0은 실제 0으로 저장한다. 기존 가져오기에서 누락을 0으로 채운 자료의 0은 미확인으로 취급한다. 음수·잘못된 숫자·유효하지 않은 날짜는 제외한다. 동일 날짜·출처·글·키워드 재가져오기는 입력된 지표만 갱신하며 빈 셀은 이미 알려진 값을 지우지 않는다. URL은 withsuzz 소유의 정확한 네이버 글 링크로 연결한다.

발행 후 28일 이상 지난 블로그 글을 글감 ID로 묶고 출처와 지표를 구분한다. 최근 14일은 한국 시간 어제까지, 각 구간 최소 7일의 실제 자료와 최근 4일 이내의 관측이 필요하다. 앞선 12개의 겹치지 않는 14일 구간 중 관측일 평균이 높은 구간을 비교한다. 이전 평균 5 이상이고 최근 평균이 절반 이하인 경우 후보가 된다. 없는 날짜는 0으로 채우지 않는다. 같은 날짜의 동일 자료는 한 번만 계산하고, 상충하는 수치는 그 날짜를 제외한다.

동일 글의 후보는 검색 유입 클릭, 방문 유입, 글 조회수 순으로 사용 가능한 감소 지표를 우선한다. 조회수 감소를 검색 유입 감소로 표시하지 않는다. 계절·행사 종료·협찬 조건을 점검하도록 안내하고 감소 원인을 확정하지 않는다.

## 기획과 추적

선택 시 추천 ID와 근거 fingerprint를 검증한다. 이미 선택한 요청을 재시도해도 같은 기획을 반환한다. 자료가 바뀐 미선택 후보는 409로 거절한다. 원본 원고·일정·게시 상태·링크·경험치는 보존한다. 새 기획은 날짜 없는 아이디어, 빈 원고, 직접 작성 구분으로 생성된다. 기존 경험을 새 방문처럼 쓰지 않는다는 안내와 공식 정보 확인 작업을 메모에 남긴다. 원본의 만료한 마감과 엠바고는 복제하지 않는다.

진행 중인 기획은 다시 열고 중복 생성하지 않는다. 새 글을 게시한 뒤 28일 동안 같은 원본의 새 추천을 제한한다. 새 글 발행 후 첫 14일의 같은 출처·지표를 관측일 수와 함께 표시한다. 자료가 없으면 집계 대기이며, 두 글의 차이를 재작성의 인과 효과로 단정하지 않는다.

일일·주간 매니저 리포트는 실제 후보와 자료 부족 사유를 포함한다. 기존 18시 리포트 예약은 변경하지 않는다. 주간 학습은 누락 셀·충돌한 날짜·키워드별 중복을 표본에 사용하지 않는다. 성과 표도 출처와 채널을 분리하고, 모든 행에 분자와 분모가 있을 때만 비율을 계산한다.

## 소유자 에이전트 경로

Sites에서 sole-owner private 접근을 확인한 뒤 반환된 사이트 원본 주소에만 서비스 토큰을 전달한다. 토큰은 세션 메모리와 숨긴 표준 입력으로만 처리한다. `/api/refresh-agent` GET은 후보·근거·기획 진행·자료 범위를 반환하며 전체 workspace나 원고를 노출하지 않는다. POST는 `{op:"choose",id,fingerprint}`만 허용한다. 최대 요청 1500자, 외부 Origin 변경 거절, 브라우저 호출은 기존 관리자 세션을 요구한다. 서비스 요청은 Sites private dispatch 경계 뒤에서만 접근한다.

## 검증

숫자 누락·실제 0·CSV 재가져오기, 출처 분리, 키워드 중복, 날짜 충돌, 오래된 자료, 계절 표시, 원본 보존, 기획 중복, 오래된 선택 거절, 발행 후 실측 추적, 관리자·Origin·허용 작업 범위와 기존 연동 보존을 단위 및 HTTP 통합 테스트로 검증한다. 실제 자료가 없는 라이브 환경에는 테스트 성과나 가짜 후보를 저장하지 않는다.
