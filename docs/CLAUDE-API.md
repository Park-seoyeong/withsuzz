# Claude로 사이트 즉시 생성

OpenAI 키 생성이 거부된 상태에서도 `사이트에서 바로 생성`을 쓸 수 있도록 Claude(Anthropic) API를 두 번째 AI 서비스로 추가했습니다. 기존 OpenAI 경로는 그대로 유지됩니다.

## 연결 방법

1. https://platform.claude.com 에서 API 키를 만듭니다(API 사용 요금은 Claude 구독과 별도입니다).
2. 호스팅의 런타임 비밀값으로 `ANTHROPIC_API_KEY`를 저장합니다. 소스·`.env` 커밋·채팅에 키를 넣지 않습니다.
3. 다시 빌드·배포합니다. 이제 빌드 전에 `npm ci`가 필요합니다(Claude SDK와 esbuild).

| 환경 변수 | 기본값 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 없음 | 있으면 Claude 경로가 켜집니다. |
| `AI_PROVIDER` | 자동 | `anthropic`(또는 `claude`)/`openai`. 비워 두면 OpenAI 키가 있을 때 OpenAI, 없으면 Claude를 씁니다. |
| `ANTHROPIC_MODEL` | `claude-opus-5-5` | 다른 Claude 모델로 바꿀 때만 지정합니다. |
| `ANTHROPIC_EFFORT` | `medium` | `low`·`medium`·`high`·`xhigh`·`max`. 높을수록 꼼꼼하지만 느리고 비쌉니다. |

관리자 설정의 연결 상태와 글쓰기 작성 방식에 `Claude`가 표시되면 연결된 것입니다. 키가 틀렸거나 잔액이 없으면 실제 첫 요청에서 실패로 기록됩니다. 연결 표시는 키가 저장됐다는 뜻이지 실제 생성 성공을 뜻하지 않습니다.

## 동작

- 공식 SDK(`@anthropic-ai/sdk`)로 Messages API를 호출하고 빌드 때 Worker 한 파일로 묶습니다.
- 고정 편집 정책·관리자 기본 프롬프트·고른 내 프롬프트·활성 학습 자료·기존 게시 원고 일부를 OpenAI 경로와 같은 내용으로 보냅니다. 고정 정책은 system에 두어 프롬프트 캐시를 씁니다.
- 결과는 기존과 같은 JSON 구조(`output_config.format`)로 받아 미리보기→적용→되돌리기 흐름을 그대로 씁니다.
- 사진(JPG/PNG/WebP)과 PDF는 실제 파일로, 텍스트 파일은 본문으로 읽습니다. 기존 첨부 제한(6개·합계 16MB)을 유지합니다.
- `최신 정보와 공식 출처 확인`을 켜면 웹 검색 도구(`web_search_20260209`, 최대 5회)를 붙입니다. 검색이 실제로 실행되지 않으면 결과에 "최신 확인 미완료"를 표시합니다. 출처는 본문 인용이 있으면 인용을, 없으면 검색한 페이지 목록을 보여주고 그 차이를 알립니다.
- 검색이 길어져 `pause_turn`으로 멈추면 최대 3번 이어서 받습니다. 웹 검색과 JSON 형식을 함께 거절하면 형식 지정 없이 한 번만 다시 요청합니다.
- 안전 분류기가 요청을 거절할 때를 대비해 `fallbacks: "default"`(베타 `server-side-fallback-2026-07-01`)를 켰습니다. 다른 모델이 대신 작성하면 결과에 그 모델 이름을 표시합니다.
- 결과 카드에 서비스·모델 이름이 표시됩니다. 실패한 요청도 기존처럼 일일 요청 수에 포함됩니다.

## 검증 범위

자동 테스트는 요청 구조, 응답 해석, 거절·키 오류·`pause_turn`·형식 거절 재시도를 가짜 응답으로 확인합니다. 실제 Claude API 호출은 이 저장소 작업 환경에 키가 없어 아직 실행하지 않았습니다. 키를 연결한 뒤 짧은 글감 하나로 실제 생성을 먼저 확인해 주세요.
