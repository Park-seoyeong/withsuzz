# 써즈의 동네방네 콘텐츠 매니저

개인용 비공개 콘텐츠 관리 사이트. 파스텔 파란색 ERP 작업 화면에 캐릭터와 성장 퀘스트를 결합합니다.

## 실행과 검증

Node.js 22 이상에서 `npm ci` 후 `npm run build`, `npm test`로 검증합니다. 빌드는 Claude SDK를 포함해 `dist/server/index.js` 한 파일로 묶습니다. 로컬 실행은 `ADMIN_PASSWORD` 환경 변수를 설정한 뒤 `npm start`를 사용합니다. 로컬 서버의 사용자 신원 주입은 개발 전용이며 배포 코드에는 포함되지 않습니다.

## 현재 구현

콘텐츠 관리와 원고 저장·검수, 지역을 분산한 일정 추천, 하루 4개 제한과 미룬 글 재배치, 협찬 단계 관리, 학습 자료실, 성장 퀘스트, 알림 센터, 수동 지표 입력·리포트, 설정과 JSON 백업을 제공합니다. 기존 노션 자료는 원문 및 원본 페이지 링크와 함께 별도 가져오기 기능으로 이전합니다.

AI 원고 생성·수정은 서버의 OpenAI Responses API를 사용합니다. 초안·전체 원고에서 요청한 부분 수정·선택 영역 수정·제목 3개 모드를 제공합니다. 결과는 원고와 분리해 미리 보여주고 적용·되돌리기를 지원합니다. 요청 이후 원고가 달라지면 자동 적용을 거절합니다. 최신 확인 옵션은 웹 검색 도구를 호출하며 검색 실행 및 반환된 인용 출처를 표시합니다. 검색 미실행·출처 누락은 확인 필요로 표시합니다. 사용자 사진·PDF·텍스트 파일은 서버에서 읽어 AI 입력으로 전달하며 읽지 못한 자료를 몰래 건너뛰지 않습니다.

런타임 `OPENAI_API_KEY` 설정이 필요합니다. 키는 Sites 지침에 따라 OpenAI Developers 플러그인의 API 키 스킬과 필요한 승인을 거쳐 비밀로 설정합니다. 기본 모델은 `gpt-5-mini`, 변경은 서버의 `OPENAI_MODEL`로 지정합니다. 요청은 100초 후 중단하고 동시 2건·기본 일일 20건을 제한합니다. 실패한 요청도 일일 횟수에 포함합니다. 프로바이더가 비용을 청구했는지와 별개로 완료·실패 상태를 기록합니다. 검색량·통계·네이버 자동 발행·학습 자료 자동 요약은 아직 별도 서비스 연결이 필요합니다.

네이버 공식 글쓰기 API는 2020-05-06 종료되었습니다(https://developers.naver.com/notice/article/7527). 네이버 로그인 API나 공개 검색 API가 비공개 블로그 통계 및 발행 권한을 제공한다고 가정하지 않습니다. 계정 연결·통계 조회·작성·예약 발행은 실제 지원되는 접속 환경에서 각각 검증해야 하며, 사이트 연결 상태에 미검증 기능을 연결됨으로 표시하지 않습니다.

## 유입 검색어 기반 글감 추천

최신 저장된 네이버 검색어와 제목·메인 키워드·검색 의도·월을 비교해 날짜 미정 글감을 추천합니다. 홈은 3개, 글감 추천 화면은 기존 후보와 새 기획 제안을 보여줍니다. 최근 14일 소재 중복과 당일 지역 중복, 협찬 마감·엠바고를 표시합니다. 7일 지난 자료는 이전 자료로 표시하며 자동 배치 가중치에서 제외합니다. 유입 비율을 전체 검색량이나 개별 글의 유입·클릭률로 환산하지 않습니다.

선택하면 기존 원고·일정을 보존하고 검색어 날짜·비율·조회 실행 URL을 근거로 저장합니다. 새 글감은 선택할 때만 등록되며 중복 선택은 같은 글감을 반환합니다. 발행일 저장은 기존 하루4개·마감·엠바고 제한을 통과해야 합니다. 일정 자동 배치에서 최근 검색어를 참고할 수 있으며 지역 분산·예약·잠근 일정은 우선 보존합니다. 추천 진행 상황의 성과는 글감 ID로 연결된 실제 지표만 표시합니다. 저장된 통계가 바뀌면 다음 화면 조회에서 추천을 다시 계산하며 AI API 키는 필요 없습니다.

## 운영

일일 리포트와 직전 완료된 주의 주간 리포트·추천 기준 검토를 저장합니다. 매니저 리포트는 성과 페이지와 알림 센터에서 확인할 수 있습니다. 주간 검토는 같은 출처의 실제 글별 지표가 3개 이상일 때만 소재 참고 점수를 제한적으로 조정하며 원래 글쓰기 원칙은 변경하지 않습니다. 소유자 비공개 무인 실행 절차와 중복 방지는 `docs/MANAGER-REPORTS.md`를 참고합니다.

배포는 Cloudflare Worker ES 모듈과 D1, R2를 사용합니다. 제공되는 Sites 서버 템플릿 소스에 접근할 수 없어 의존성이 없는 Worker 구현을 사용했습니다. `.openai/hosting.json`의 기존 project_id를 유지합니다. 관리자 비밀번호와 가져오기 토큰은 Sites 런타임 비밀로 설정하며 소스·백업에 포함하지 않습니다. 인증은 Sites 사용자 신원과 서버 세션을 함께 검증합니다.

전체 기획 및 제약은 `docs/IMPLEMENTATION.md`에 있습니다. `.sites-runtime/`과 `data/`는 Git과 배포에서 제외되는 로컬 자료입니다.
## 내 Cloudflare 계정으로 배포

`wrangler.toml`이 포함되어 있어 Cloudflare Workers(무료)에 바로 올릴 수 있어요. 단계별 방법·비밀값·자료 옮기기는 [docs/CLOUDFLARE-DEPLOY.md](docs/CLOUDFLARE-DEPLOY.md)에 있어요.

## Claude로 사이트 즉시 생성

OpenAI 키가 없어도 런타임 비밀값 `ANTHROPIC_API_KEY`를 저장하면 `사이트에서 바로 생성`이 Claude로 동작합니다. 설정·동작·검증 범위는 [docs/CLAUDE-API.md](docs/CLAUDE-API.md)에 있습니다.

## 내 프롬프트 라이브러리

관리자 설정에서 자주 쓰는 프롬프트를 저장하고 글쓰기 작업실에서 골라 초안·수정 요청에 함께 보냅니다. 사이트 즉시 생성, ChatGPT 대화 작성, 작성 프롬프트 복사가 모두 같은 프롬프트를 사용하며 고정 편집 원칙이 우선합니다. 자세한 내용은 [docs/PROMPT-LIBRARY.md](docs/PROMPT-LIBRARY.md)에 있습니다.

# API 키 없는 ChatGPT 에디터

사이트 전용 MCP 플러그인으로 글감·메모·연결된 첨부를 읽고 초안·수정안·필수 질문을 결과 미리보기에 저장할 수 있습니다. 글쓰기의 작성 방식에서 `ChatGPT 대화에서 작성`을 선택하고 이 대화에서 이어서 처리합니다. 원고 적용·되돌리기는 기존 검증을 사용하며 일정과 외부 발행은 바꾸지 않습니다. 사이트 즉시 생성용 OpenAI API 연결과 별개입니다. 연결·인증·검증 범위는 [docs/CHATGPT-EDITOR.md](docs/CHATGPT-EDITOR.md)에 있습니다.

학습 자료실에서도 ChatGPT 분석 요청을 저장하고 요약·학습 포인트·써즈 적용점을 원문별로 기록합니다. 읽은 첨부·확인한 링크·접근 실패를 구분하며 활성 체크와 고정 원칙을 보존합니다.

## 발행 관리

완성 원고에서 `발행 준비`를 눌러 한국 시간의 발행 시각과 실제 첨부 사진의 위치·이용 권한을 저장합니다. 마감·엠바고 시각, 제목/본문 키워드, 분량·광고 고지와 자료 변경을 검사합니다. 아시아 이슈와 브랜드 커넥트는 새벽 1시 각 1개로 구분하고 직접 글 하루4개 제한과 분리합니다. 실제 네이버에서 확인한 예약·게시 증거가 있을 때만 글감 상태와 링크를 갱신합니다. 실행 중 응답이 끊기면 결과 확인 전에는 재발행하지 않습니다. 원고·일정·통계 연동은 보존합니다.

현재 배포에는 새벽 자동 발행 실행 예약이 연결되지 않았고, 네이버 글쓰기 인증과 이미지 업로드 경로도 미검증입니다. 사진 위치 저장은 이미지 자동 생성·상세 페이지 자르기를 대신하지 않습니다. 실제 기능 범위와 소유자 에이전트 실행 절차는 [docs/NAVER-PUBLISHING.md](docs/NAVER-PUBLISHING.md)를 참고합니다.

## 과거 글 재작성 추천

`글감 추천 → 과거 글 재작성`에서 발행된 글의 같은 출처·같은 지표를 비교합니다. 최근 14일과 이전 6개월 안의 14일 구간에 각각 최소 7일의 실제 관측값이 있는 경우, 이전 평균 5 이상·최근 50% 이상 감소한 후보를 보여줍니다. 검색 클릭·방문 유입·조회수를 구분하며 계절·행사 종료 가능성과 누락 날짜를 표시합니다. 선택하면 원본을 보존한 새 기획과 추천 근거를 저장하고, 새 글 발행 후 첫 14일의 같은 지표를 따로 추적합니다. 일일·주간 리포트에도 후보가 포함됩니다.

CSV는 글감 ID 또는 정확한 원본 링크로 연결합니다. 빈 값과 실제 0을 구분하고 출처가 다른 성과를 섞지 않습니다. TinyFish의 실제 글별 일간 조회수 수집은 별도 `/api/naver-post-sync` 경로로 저장하며 기존 오전 9시 갱신 작업에 함께 등록할 수 있습니다. 현재 네이버 상세 화면은 최근 15일을 표시하므로 확인한 날짜를 누적하고, 과거 날짜 선택기로 확인한 글별 하루값만 추가합니다. 전체 글이나 과거 6개월을 일괄 수집했다고 표시하지 않습니다. 블로그 전체 방문자나 유입 검색어 비율만으로 재작성 후보를 만들지 않습니다. 실제 범위와 실행 경로는 [docs/REFRESH-RECOMMENDATIONS.md](docs/REFRESH-RECOMMENDATIONS.md)에 있습니다.
